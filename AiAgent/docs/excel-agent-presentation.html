03 核心功能

功能矩阵

类别 工具函数 功能说明
读取 excel_read_file 读取文件概要（工作表、列头、示例数据）
读取 excel_read_sheet_data 读取指定工作表的详细数据
读取 excel_read_cell 读取特定单元格或区域
创建 excel_create_file 创建新的 Excel 文件（含表头）
写入 excel_write_cells 写入单个单元格
写入 excel_append_row 追加新行到末尾
管理 excel_add_sheet 添加新的工作表

读取功能详解

excel_read_file

  • 自动扫描所有工作表
  • 提取列标题
  • 返回示例数据
  • 快速了解文件结构

excel_read_sheet_data

  • 支持指定工作表
  • 可限制返回行数
  • 保留 Excel 行号
  • 适合查看详细数据

excel_read_cell

  • 单个单元格 (A1)
  • 区域范围 (A1:C5)
  • 适合精确查找
  • 快速定位数据

写入功能详解

excel_create_file

  • 自动创建目录
  • 支持自定义表头
  • 可预填充数据
  • 返回创建结果

excel_write_cells

  • 精确定位单元格
  • 支持字符串和数值
  • 自动创建文件/工作表
  • 灵活写入数据

excel_append_row

  • 自动追加到末尾
  • 批量添加记录
  • 无需计算行号
  • 简化操作流程

核心代码示例

class ExcelAgent:
    def __init__(self, llm=None, max_iterations=10):
        self.llm = llm or init_llm()
        
        # 注册 9 个工具
        self.tools = [
            excel_read_file,
            excel_read_sheet_data,
            excel_create_file,
            excel_write_cells,
            excel_append_row,
            # ... 更多工具
        ]
        
        # 创建 Agent
        self.agent = self._create_agent()

# 使用示例
agent = ExcelAgent()
agent.invoke("创建一个员工信息表")

05 使用示例

示例 1：查看文件内容

您: 帮我看看 C:/data/员工信息.xlsx 有什么内容

Agent: 我来读取这个文件...

[调用工具: excel_read_file]

# 结果：
## Sheet: 员工表
- Rows: 50, Columns: 5
- Headers: 姓名 | 部门 | 职位 | 电话 | 入职日期

| 行号 | 姓名 | 部门 | 职位 | 电话 | 入职日期 |
|------|------|------|------|------|----------|
|  2   | 张三 | 技术部 | 工程师 | 138**** | 2023-01-15 |

示例 2：创建新文件

您: 创建一个学生成绩表，包含姓名、语文、数学、英语

Agent: 我来创建这个文件...

[调用工具: excel_create_file]

# 结果：
Excel file created successfully!
Path: C:/data/成绩表.xlsx
Sheet: Sheet1
Columns: 5 (姓名, 语文, 数学, 英语, 总分)

示例 3：添加数据

您: 在成绩表里添加一条记录：张三，95，88，92

Agent: 我来添加这条记录...

[调用工具: excel_append_row]
参数: values=["张三", "95", "88", "92"]

# 结果：
Appended 4 value(s) to row 2

操作完成！
